# Лабораторная работа № 3 - Асинхронный JavaScript и REST API

## Результаты проверки
- **GET-запрос**: При нажатии кнопки «Загрузить публикации» выполняется запрос к `https://jsonplaceholder.typicode.com/posts?_limit=5`, после чего на странице динамически отображаются 5 постов с заголовками и текстом.
- **POST-запрос**: Форма проверяет поля на наличие текста. При отправке данные уходят методом POST на сервер, после чего выводятся сообщение об успехе, ID созданной записи и сам пост в списке.
- **Обработка ошибок и состояний**: Во время запросов отображается статус загрузки. При попытке ввода некорректного адреса выводится сообщение об ошибке.
